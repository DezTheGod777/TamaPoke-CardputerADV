# TamaPoke Cardputer ADV v0.9.0 — Release Notes

**Status:** Hardware-approved on physical M5Stack Cardputer ADV

v0.9.0 is a major expansion of the Cardputer ADV fork. It preserves the original TamaPoke core—time-based leveling, Gen-1 lifecycle/evolution logic and v0.7-compatible pet journal—while adding a much larger handheld feature set.

## Download

Use the normal release firmware:

```text
TamaPoke-CardputerADV-v0.9.0.bin
```

This is the normal application BIN intended for ordinary installation, including M5 Launcher.

An optional `TamaPoke-CardputerADV-v0.9.0-full-flash.bin` may be generated by CI for advanced recovery workflows; it is not the normal install file.

## Major additions

- Persistent personality traits and live moods
- Richer idle/species/habitat/time-of-day behavior
- Home Customize with Starfield and redesigned Dream backgrounds
- Earned plants, beds, toys, trophies and decor
- Inventory / Bag, Poke Shop and coin economy
- Six additional minigames with saved high scores
- Daily Life rewards/events/greetings/visitors/time-together tracking
- Deeper Pokédex History and favorites
- Three-slot Save Manager with verified restore
- Expanded event-only audio and Pokémon cries
- Improved evolution/shiny/sleep/recovery animation polish
- 12-hour Clock / Calendar with seconds, weekday and full date
- Original PMD Gastly/Haunter/Gengar sprites on the clock screen
- Manual full date/time editor
- One-shot Wi-Fi/NTP time sync
- Reusable saved Wi-Fi credentials after a successful connection
- Central TamaPoke Hub plus direct keyboard shortcuts

## Hardware-test fixes included

The release includes the final physical-device fixes found during v0.9.0 testing:

- Wi-Fi Time Sync picker keyboard handling restored
- Wi-Fi menu no longer appears frozen after network scan
- Wi-Fi radio is not touched just by opening the picker
- network scan/connect flows are bounded and radio shuts down after sync
- saved Wi-Fi persistence hardened with internal Preferences plus SD fallback
- Wi-Fi passwords preserve case and symbols
- Clock battery icon uses the transparent Home-style treatment
- hand-drawn ghost clock artwork replaced with original PMD sprites
- clock sprite size/position rebalanced for the 240×135 display
- Gengar moved to avoid the full-date line
- `GHOST CLOCK` development label removed
- Starfield code retired and Starfield made directly selectable
- Dream made directly selectable and its artwork redesigned
- 151 Master Border removed completely
- Daily Together bug fixed to use actual pet age in full days
- Bond local-day/persistence behavior audited and hardened
- poop icon outline polished without changing original poop frequency

## Important compatibility notes

Core pet saves remain:

```text
/tamapoke_v7_a.bin
/tamapoke_v7_b.bin
```

v0.9.0 stores most new systems in separate auxiliary files rather than changing the pet journal format.

Before updating, back up the entire SD card.

## Original mechanics deliberately unchanged

- 1 real minute = 1 in-game minute
- +1 level every 60 real minutes
- no XP grinding from minigames
- care mistakes can delay evolution
- Evo Charm cannot bypass the real species evolution level/path
- offline catch-up remains capped at about two weeks when a newer valid clock is available
- scene times remain sunrise 06:00–07:59, day 08:00–17:59, sunset 18:00–19:59, night 20:00–05:59
- no looping background music/audio ambience

## Secret-content release changes

Starfield and Dream are no longer hidden. The 151 border is removed.

Optional Mew Visitor, Mystery Gift and Ultra Shiny easter eggs remain. See `docs/SECRETS.md` for spoilers.
